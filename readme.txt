～あらすじ～
　神々が統治する世界ブリトデネク。
ブリトデネク中を旅する冒険者のあなた(たち)は、ミストゲイルという街に向かう途中で奇妙な夢を見る。
夢には見たこともない子供が現れ、世界滅亡をたくらむ人物が近々現れることを告げられ、それを止めてほしいと頼まれる。
果たしてあなた(たち)がミストゲイルで目にするものとは…？

コマンド等では絶対に設定しないでください。



●困った時のQ&A
Ｑ：街中で死んでスペクテーター(半透明)になっちゃった！？
　　もとに戻れないの？
Ａ：リログ(ワールドを閉じた後再びワールド内に入る)をすれば直ります。

Ｑ：魔法球？宝具？何これ？
Ａ：このワールドでは、コマンドによって、魔法や剣術、弓術等のシステムがあります。

Q:剣と斧はわかるけどナイフ？大鎌？
Ａ:本ワールドでは剣と斧の他にもナイフや大鎌といった武器があります。
　ナイフは攻撃力が低くエンチャントができない短所がありますが、
　クールタイムがほとんど存在せず、連打しても攻撃力が落ちません。
　大鎌はクールタイムが非常に長くエンチャントができない短所がありますが、
　攻撃力が高く、攻撃時に周囲4mに魔法の斬撃攻撃を行えます。

Q:魔法が効かない敵がいるんだけど？
Ａ:本ワールドには一部魔法が一切効かない敵モブも存在します。
　逃げることや、攻撃手段を変更するのも戦術です。

Q:この敵硬すぎじゃない？
A：本ワールドには魔法が効かない敵モブと対照的に、ファントム属性と呼ばれる種類の敵モブも存在します。
　ファントム属性のモブは武器を使った攻撃によるダメージを大幅に軽減できますが、
　魔法には一切耐性が無く、体力も低く設定されています。

Ｑ：ダンジョンってどうやっていけばいいの？
Ａ：街の門付近にある食べ物屋の掲示板にダンジョンの名前が書かれた掲示板があります。
　　その掲示板のスイッチを押した後、街の門をくぐるとダンジョンに出発します。
　　この時、マルチプレイの場合はすべてのプレイヤーがダンジョンに向かうこととなるのでご注意ください。

Ｑ：ベッドとかって意味あるの？
Ａ：このワールドでは睡眠をとるとボーナスがつくようになっています。

Ｑ：作業台ってどこにあるの？
Ａ：家を購入し、ある追加オプションを購入することで使用可能となります。

Ｑ；スターシロップを飲んだらデバフ効果が消えないんだけど…。
Ａ：スターシロップのデバフ効果は再度スターシロップを飲むか、大地の雫を飲まない限り消えません。

Ｑ：お金が足りない！
Ａ：ダンジョンに潜るか街にいる人の相談を聞いてみましょう。また、釣りをしてみると…？

Ｑ：○○って不具合？仕様？
Ａ：配布場所の非公式フォーラムまたは、私のツイッター(@gol559)まで連絡いただければ、可能な限り対応いたします。
　　不具合報告の際はバージョンやシングルまたはマルチプレイか、などの情報を教えていただけると助かります。

Ｑ：バージョン1.9以前または1.11以降じゃできなの？
Ａ：オフハンド等のギミックや、新しいコマンドを多用しているため、1.9以前及び1.11以降のバージョンではプレイできません。

Ｑ：動画・生放送に使いたいんだけど？
Ａ：ご自由にお使いください。動画や生放送のURLをはっていただければ、拝見したいと思います。
